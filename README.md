
LqDFx's Extras
=======

This mod is just a person project to learn more about minecraft modding and see
if I can accomplish some of the things others have done while building my skills!

Things in this mod:
* Entity Rules:
  * Creepers Burn - Option to have Creepers burn in the daylight like Skeletons and Zombies
  * Evoker Death - When a Evoker dies, the Vex spawned die with it!
  * Mob Griefing - Optional switches for per mob griefing.
  * Mob Spawning
    * Option to disable Vex from spawning.
    * Option to turn Skeletons to Wither Skeletons in the Nether.
  * TNT Breaks Bedrock - Magic! Configurable radius.
  * Hoe upgrades:
    * Crop Replanting
    * Area Tilling
  * Mining Speed improvements:
    * Beacon mining with a Diamond/Netherite PickAxe Efficiency 5 insta-mines all blocks
    * Efficiency and Hardness-scaled per block mining speed tweaks
